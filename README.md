# HoneyBaked 10U calendar feeds

Public subscribe-able ICS files for Girls 10U HB Gold. These calendars do **not** include home addresses.

Source generator (private): [HBScheduleICS](https://github.com/ryanmartini-us/HBScheduleICS)

## Subscribe

| Family | Calendar |
|---|---|
| Ryan | [ryan.ics](https://ryanmartini-us.github.io/HB10U_ScheduleExpander/ryan.ics) |

Apple Calendar: File → New Calendar Subscription → paste the `.ics` URL.  
Google Calendar: Settings → Add calendar → From URL.

Each feed includes the original TeamSnap ice event, an arrival block when TeamSnap lists an arrival time, and a commute block sized from that family's home.
